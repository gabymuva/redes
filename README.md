# Red en movimiento

Guía interactiva en español sobre redes informáticas y la arquitectura de red de una pequeña empresa.

## Publicar en GitHub Pages

Este sitio es estático: no necesita Node.js, compilación ni dependencias. La página de entrada `index.html` abre la guía original.

1. Sube todos los archivos y carpetas de este proyecto a la raíz de un repositorio de GitHub.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, selecciona **Deploy from a branch**.
4. Elige la rama `main` y la carpeta `/(root)`, y guarda los cambios.
5. Espera a que termine la publicación. La URL del sitio aparecerá en esa misma sección.

> Si cambias el nombre de la rama principal, selecciona esa rama en la configuración de Pages.

## Archivos

- `index.html`: entrada del sitio y redirección a la guía.
- `guia_red_pequena_empresa .html`: página interactiva completa, con estilos y JavaScript incluidos.

La guía carga las fuentes DM Sans y Manrope desde Google Fonts; si no hay conexión, se mostrarán fuentes de respaldo.
